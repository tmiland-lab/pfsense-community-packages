pfsense-community-packages

Unified pkg(8) repository for community and mirrored pfSense packages — packages dropped from or absent in the official pfSense repository, plus first-party packages. Install/upgrade/remove them with the Community Packages manager or plain pkg-static.

Repo URL for /usr/local/etc/pkg/repos/community.conf:
https://tmiland-lab.github.io/pfsense-community-packages/repo

Metadata is signed; the trust anchor is installed by the manager package (signature_type: fingerprints).
